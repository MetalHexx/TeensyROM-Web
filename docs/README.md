# TeensyROM Suite documentation

TeensyROM Suite is four ways to run your TeensyROM cartridge and your Commodore 64: a web app, a command line, a Claude Code companion and an API. They share one download and one library.

- [Getting started](getting-started.md): install and update the suite, connect your cart and prepare your library.
- [Trom UI](trom-ui.md): the web app for playing, searching, copying files, watch folders and themes.
- [DJ Mixer](dj-mixer.md): two SID decks played live through real C64s.
- [Trom Terminal](trom-terminal.md): the guided menu and one-line commands.
- [Trom Agent](trom-agent.md): your TeensyROM companion in Claude Code.
- [Trom API](trom-api.md): start and stop Trom API, and build your own tools on it.
- [Contributing](contributing.md): build the suite from source.
