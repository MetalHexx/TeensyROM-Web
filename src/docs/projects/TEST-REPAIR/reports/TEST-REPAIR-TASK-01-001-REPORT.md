## 🔧 Implementation Details

**Approach**: Override the inferred `vite:test` target with a simple echo command that always succeeds.

**Rationale**: 
- Empty target overrides `{}` don't disable inferred targets in Nx (they get merged)
- Using plugin `exclude` would require modifying `nx.json` (not in task scope)
- Echo command approach:
  - Clearly communicates intent ("No tests for...")
  - Always passes (exit code 0)
  - Fast execution
  - No dependencies

**Changes Made**:

`api-client/project.json`:
```json
"vite:test": {
  "command": "echo No tests for generated api-client"
}
```

`app-bootstrap/project.json`:
```json
"vite:test": {
  "command": "echo No tests for app-bootstrap"
}
```
