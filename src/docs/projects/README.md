# Orchestrated Projects

This folder contains all projects managed through the subagent orchestration system.

## Structure

Each project has its own isolated folder with the following structure:

```
project-name/
├── master-plan.md          # High-level project plan
├── phases/                 # Phase planning documents
│   ├── phase-01-[name].md
│   └── phase-02-[name].md
├── tasks/                  # Task handoff documents
│   ├── TASK-01-001-[name].md
│   └── TASK-02-001-[name].md
└── reports/                # Worker completion reports
    ├── TASK-01-001-report.md
    └── TASK-02-001-report.md
```
